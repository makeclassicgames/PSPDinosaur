# MS Patman

PSP (PlayStation Portable) homebrew Game. This game is a clone of the "Google Chrome Dinosaur Game", but with a Duck. In this game, you control a duck that must jump over obstacles to avoid crashing. The game keeps track of your score based on how long you survive.

![MS Patman Screenshot](screenshot.png)

## Features

- Simple and addictive gameplay
- Score tracking
- Retro-style graphics
- Easy controls (jump with a button press)
- Made with PSP SDK and [Raylib port](https://github.com/raylib4Consoles/raylib4Psp).

## Requirements

- PSP Console or PSP Emulator
- PSP SDK installed for building the game and Raylib port.

## Controls

- Jump: Press the "X" button.
- Pause/Resume: Press the "Start" button.
- Crouch: Press Down on the D-pad.

## Installation

1. Download the latest release of MS Patman from the releases section.
2. Extract the contents of the ZIP file to your PSP's memory stick or emulator's game directory (e.g., /PSP/GAME/MSPatman).
3. Navigate to the game on your PSP or emulator and launch it.
